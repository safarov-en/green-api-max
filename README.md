# GREEN-API MAX Chat Client

Клиентское веб-приложение на React для отправки и получения сообщений в мессенджере MAX через сервис GREEN-API.

## Стек технологий
- React 18 / 19
- Vite
- CSS3 (стилизация под интерфейс MAX Web / WhatsApp Web)
- GREEN-API (HTTP API: sendMessage, receiveNotification, deleteNotification)

## Функционал
- Авторизация по учетным данным GREEN-API (`idInstance`, `apiTokenInstance`, `apiUrl`).
- Создание чата по номеру телефона получателя в международном формате.
- Отправка текстовых сообщений адресату в мессенджер MAX.
- Получение входящих сообщений в реальном времени с использованием механизма polling очереди уведомлений (Long Polling).
- Сохранение активных чатов и истории переписки при перезагрузке страницы.

## Инструкция по локальному запуску

1. Репозиторий:
   \`\`\`bash
   git@github.com:safarov-en/green-api-max.git
   cd green-api-max
   \`\`\`

2. Установить зависимости:
   \`\`\`bash
   npm install
   \`\`\`

3. Запустить проект в режиме разработки:
   \`\`\`bash
   npm run dev
   \`\`\`

4. Открыть в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).
